# WebSSH Shell 上下文：第一版验收记录

日期：2026-09-11。分支：`feature/webssh-completion`。

## 本次交付

- 测试环境已部署连接级 Shell 上下文；新建或重连 WebSSH 后使用。
- 补全默认仅共享草稿，可显式增加目录、最近命令及有限输出。
- 上下文由后端按当前用户和连接获取，前端不能上传伪造的历史对象。
- Sidepanel 的 `terminal.read` 可读取同一连接的结构化上下文；聊天与补全仍是独立会话。
- Bash 历史不可用或忽略命令时，来源为未知，不将前一条命令错配到本次输出。
- 只展示/填入模型建议，不自动回车执行。切换共享范围取消旧建议并关闭自动提示。

设计、边界与使用方法见 [方案调研](webssh-completion-research.md) 和 [使用说明](../webssh-completion.md)。

## 未通过 / 未覆盖

- **已有状态码问题**：普通用户请求他人的 WebData 资源返回 HTTP 500，而非预期 404。响应没有返回资源数据；该断言失败，不计为通过。本次未修改相关错误映射。
- **SQL Server**：测试容器不可用，原生集成缺少测试 DSN 并明确跳过，未计为通过。
- **VNC**：缺少可用的保存连接夹具，本次未运行真实 VNC E2E。
- Zsh/Fish、多行、行中编辑及精确编辑缓冲区仍未适配；Shell 历史和输出关联是尽力而为，不保证任意用户 Shell 配置下精确。

因此本轮不是“所有 E2E 全绿”，而是本次 Shell 上下文功能和以上可运行回归通过，另有一项已有状态码缺陷及两项环境缺口。
