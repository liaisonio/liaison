# Liaison v1.16.0-rc.2

This release candidate includes the on-demand TCP access and connector discovery improvements from v1.16.0-rc.1, plus a login error localization fix.

## Fixed

- Login failures now follow the selected console language, including when the language changes after an error.
- Invalid credentials use a consistent message. Unexpected server errors are not displayed verbatim on the public login page.
- Added regression coverage for invalid credentials, disabled accounts, rate limiting, and safe fallback messages.

## Installation and upgrade

- Use the Docker bundle for the standard installation, or the systemd bundle for a native Linux installation.
- Back up existing configuration and data before upgrading. Retain existing configuration, certificates, and persistent data.
- This is a prerelease for testing. The stable release remains v1.15.4.

## Verification scope

The login fix passed unit tests, a production web build, and browser checks with simulated authentication failures in Chinese and English at desktop and mobile sizes. These checks do not replace deployment-specific authentication or upgrade validation.
