# Liaison v1.15.0-rc.1

This is a release candidate for evaluation, not the stable release.

## Highlights

- Use installed Codex and Claude Code through an owned Liaison connector, with separate native protocol adapters and shared conversation UI.
- Persistent encrypted server history, explicit native-session resume, project-grouped conversations, history search and draft preservation.
- Project selection before creating a conversation, recent project shortcuts, model selection and native command catalogs.
- Improved streaming activity, one-shot approval and question cards, safe Markdown, Mermaid viewing, syntax-highlighted code and project-file previews.
- Codex file/image attachments and authorized project-file upload/download. Claude Code attachments remain unavailable.
- Session details separate browser observations, Manager request handling and connector-local turn timings. These are not pure model or network latency measurements.
- Consistent access empty states, URL-backed filters and navigation order: All access, Web, LLM, Agent, SSH/SFTP, TCP, Database, Cache, Desktop, Storage.

## Upgrade and rollback

- Upgrade Manager/web and the relevant Edge together to use the new Agent capabilities. Older connectors do not provide the new timing fields.
- Before upgrading from 1.14.1, back up the database, configuration, encryption material and connector instance state. Preserve the device's native Agent history as well; server display history alone cannot resume a native session.
- Schedule connector updates while Agent turns are idle. Runtime processes may reconnect or require explicit resume; do not resend a message whose delivery is uncertain.
- Keep the previous installation packages. For rollback, use the prior binaries with the corresponding pre-upgrade backup; do not assume an older version understands new records. Restoring a backup loses changes made after that backup.
- Existing server conversation history does not automatically expire. Runtime idle reclamation is separate from history retention.

## Known limits

- Native Agent execution and interruption/resume have been exercised on macOS. Linux binaries are built, but Linux native-Agent runtime validation remains incomplete.
- Windows Edge packaging does not imply Windows Agent execution support. Native Agent launch on Windows remains disabled pending process supervision and native validation.
- Claude Code image/file message attachments, multi-select questions and permanent permission grants are not supported. Unsupported interactions fail closed.
- Claude Code model names can be aliases mapped by local provider settings. A catalog entry does not guarantee the configured provider accepts it; image support is provider-dependent.
- The command menu contains only commands loaded by the isolated native process. Project hooks, extra tools and MCP/plugin configurations are not enabled simply to populate it.
- Native resume is limited to Liaison-created bindings with the original project, installation and local checkpoint available. Existing unrelated desktop sessions are not imported.
- Agent timing does not separately measure pure inference latency. Tool execution and approval waits can contribute to turn duration.

## Verification before tagging

- Local full-repository Go build and race tests passed.
- Isolated Claude Code tests passed for active text-stream interruption, subsequent sending, process restart and exact-session context recovery.
- Browser fixtures passed across Chinese/English, light/dark and desktop/mobile for navigation, Claude interactions, reload/reconnect without replay and timing diagnostics.
- An isolated database migration check using the published 1.14.1 Manager preserved synthetic application/access records, created the new Agent tables and passed SQLite integrity checking. This was a database-only check, not a complete installer upgrade rehearsal.
- Native tools-disabled tests and synthetic browser fixtures do not substitute for Linux/Windows runtime validation or a production upgrade test.

## 中文摘要

本版本为 **预发布候选版**，主要提供 Codex / Claude Code 接入、持久会话、项目导航、权限交互、文件预览和分段耗时诊断，并统一访问页面体验。

升级前请备份数据库、配置、加密材料、连接器实例状态及设备原生会话记录，在任务空闲时更新 Manager 和 Edge。云端展示历史不等于原生执行检查点。

当前原生 Agent 运行验证以 macOS 为主；Linux 原生运行仍需补验，Windows Agent 启动暂不开放。Claude Code 暂不支持消息附件、多选问题及永久授权。建议先在测试环境验证，再决定是否用于重要任务。
