# Integration artwork

MariaDB, Microsoft SQL Server and Oracle SVGs come from
[Devicon](https://github.com/devicons/devicon), distributed under its
[MIT license](https://github.com/devicons/devicon/blob/master/LICENSE).
Brand names and logos remain the property of their respective owners.

- `icons/mariadb/mariadb-original.svg`
- `icons/microsoftsqlserver/microsoftsqlserver-original.svg`
- `icons/oracle/oracle-original.svg`

ClickHouse and Elasticsearch also use Devicon (MIT):

- `icons/clickhouse/clickhouse-original.svg`
- `icons/elasticsearch/elasticsearch-original.svg`

OpenSearch uses [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/opensearch.svg)
under [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md),
with the brand blue applied to the path.

AI provider marks use [Lobe Icons](https://github.com/lobehub/lobe-icons)
under its [MIT license](https://github.com/lobehub/lobe-icons/blob/master/LICENSE).
Each mark is placed on the same padded neutral tile for light/dark readability.
Source paths under `packages/static-svg/icons/`:

- `openai.svg` → `openai.svg`
- `claude-color.svg` → `anthropic.svg`
- `gemini-color.svg` → `gemini.svg`
- `deepseek-color.svg` → `deepseek.svg`
- `zai.svg` → `zhipu.svg`
- `kimi-color.svg` → `kimi.svg`
- `minimax-color.svg` → `minimax.svg`
- `xiaomimimo.svg` → `mimo.svg`

Logos identify supported integrations, not endorsement or partnership.
