## 🌐 功能模块说明

### 1. 访问管理
- 创建公网访问，映射到内网应用
- 支持 TCP/UDP 协议
- 查看访问状态和关联应用
- 复制公网访问信息

### 2. 设备管理
- 查看设备列表（操作系统、CPU、内存、磁盘）
- 展示设备网卡信息（名称、IP、MAC）
- 按设备名或网卡 IP 搜索
- 查看设备详情

### 3. 连接器管理
- 创建连接器并获取安装命令
- 查看连接器在线状态和运行状态
- 扫描内网应用
- 关联设备，按设备名搜索

### 4. 应用管理
- 注册内网应用（SSH、Web、数据库等）
- 查看应用关联的访问
- 快速创建访问
- 按应用名或设备名搜索

### 5. 用户管理
- 用户登录/登出
- 修改密码
- JWT Token 自动续期和失效处理

## 🔌 后端 API 接口文档

### 基础信息
- **Base URL**: 与管理控制台同源的 `/api`
- **API Prefix**: `/api/v1`
- **认证方式**: Bearer Token (JWT)
- **响应格式**: JSON

### 通用响应结构
```typescript
{
  code: number;       // 200: 成功, 401: 未授权, 500: 服务器错误
  message: string;    // 响应消息
  data?: any;         // 响应数据
}
```

---

### 1. 认证接口 (IAM)

#### 1.1 登录
```
POST /api/v1/iam/login
Content-Type: application/json

Request:
{
  "email": "string",
  "password": "string"
}

Response:
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "string",
    "user": {
      "id": number,
      "email": "string",
      "name": "string"
    }
  }
}
```

#### 1.2 获取当前用户信息
```
GET /api/v1/iam/profile
Authorization: Bearer <token>

Response:
{
  "code": 200,
  "data": {
    "id": number,
    "email": "string",
    "name": "string"
  }
}
```

#### 1.3 修改密码
```
PUT /api/v1/iam/user/password
Authorization: Bearer <token>

Request:
{
  "old_password": "string",
  "new_password": "string"
}
```

#### 1.4 登出
```
POST /api/v1/iam/logout
Authorization: Bearer <token>
```

## 🚀 部署说明

### 开发环境部署

#### 1. 环境要求
- Node.js >= 16.x
- pnpm >= 8.x
- 现代浏览器（Chrome/Firefox/Edge 最新版）

#### 2. 安装依赖
```bash
cd /d/work/demome/network
pnpm install
```

#### 3. 配置后端地址
开发环境通过环境变量配置代理目标：
```bash
LIAISON_API_TARGET=http://your-backend-server:8080 pnpm dev
```

#### 4. 启动开发服务器
```bash
pnpm dev
# 或
pnpm start
```

访问：http://localhost:8000

---

### 生产环境部署

#### 1. 构建生产版本
```bash
pnpm build
```

构建产物位于 `dist/` 目录。

#### 2. 部署到 Nginx

**Nginx 配置示例：**
```nginx
server {
    listen 80;
    server_name your-domain.com;
    
    # 前端静态文件
    location / {
        root /var/www/liaison/dist;
        try_files $uri $uri/ /index.html;
        index index.html;
    }
    
    # 访问后端 API
    location /api/ {
        proxy_pass http://liaison-manager:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    
    # Gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;
}
```

#### 3. 部署步骤
```bash
# 1. 上传构建产物
scp -r dist/* user@server:/var/www/liaison/dist/

# 2. 重启 Nginx
sudo nginx -t
sudo systemctl reload nginx
```

#### 4. Docker 部署（可选）

**Dockerfile 示例：**
```dockerfile
FROM nginx:alpine

# 复制构建产物
COPY dist/ /usr/share/nginx/html/

# 复制 Nginx 配置
COPY nginx.conf /etc/nginx/conf.d/default.conf

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
```

**构建和运行：**
```bash
docker build -t liaison-frontend .
docker run -d -p 80:80 liaison-frontend
```

## 🔒 安全说明

### 认证机制
- 使用 JWT Token 进行用户认证
- Token 存储在 localStorage
- Token 失效（401）自动跳转登录页
- 请求拦截器自动添加 Authorization 头

### 权限控制
- 未登录用户自动跳转到登录页
- 支持基于路由的权限控制
- 敏感操作需要二次确认

### 安全建议
- 生产环境建议使用 HTTPS
- 定期更换 JWT Secret
- 设置合理的 Token 过期时间
- 启用 CORS 白名单
- 配置 CSP 策略
